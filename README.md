
# Zig Messaging System

## Usage

* **To compile both executables:**

```Bash
zig build
```

* **To run the server:**

```Bash
zig build run-server
```

* **To run the client:**

```Bash
zig build run-client
```

* **To pass arguments to either program:**

```Bash
zig build run-client -- 127.0.0.1 8080
```
